# Maintaining this skill package

Keep reusable operating procedures here and user collections outside this repo.
Do not embed installation paths, credentials, real channel allocations, private
provider engines or an owner's production ledger.

Use the native installed HDS workflow. Read the relevant skill reference before
changing its procedure. Preserve user choices instead of turning one production
wave's counts, providers or storage budget into fixed requirements.

Run the stdlib tests for helper changes. Validate the skill manifest and relative
references when editing the package. Verify examples against meaningful scenarios:
new Master, existing independent collection, unavailable Shared provider, title
reuse and resuming partial output. Never buy generation for package validation.

Do not publish unrelated files or claim live cross-agent/device verification
from a structural check or a fixture test.
